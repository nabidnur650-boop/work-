# License status

No active repository-wide license is asserted by this technical build because
the accountable copyright holder has not been supplied or approved. Under
default copyright rules, absence of an active license does not grant reuse
rights.

`LICENSE.template` contains the intended MIT text for original repository code
and documentation. Before public release, the accountable rights holder must:

1. confirm that MIT is the intended license;
2. replace `<COPYRIGHT HOLDER>` with the correct legal holder;
3. save the approved text as `LICENSE`; and
4. confirm the separate terms of all third-party datasets, models, and
   implementations.

Third-party assets are not relicensed by this repository. See
`THIRD_PARTY_ASSETS.md`.
